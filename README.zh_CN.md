# LEO RADIO 城市网络收音机 1.4.3

这是在已验证稳定的 1.3.6 基础上增加定时播放、屏幕与网络管理功能的版本。本版本不包含制作者的 Wi-Fi 名称、密码或其他个人资料。

## 本次更新

- 主界面频道编号右侧显示定时播放的剩余时间，并每秒更新。
- 设置中的定时播放可选择无定时、15、30、60 或 90 分钟。
- 到时停止播放、关闭无线网络和屏幕，并进入深度睡眠；重新上电后定时默认为关闭。
- 新增屏幕设置，亮度可选 25%、50%、72% 或 100%。
- 自动熄屏可选关闭、30 秒、1 分钟、5 分钟或 10 分钟；熄屏不停止播放。
- 熄屏后任意按键只唤醒屏幕，不会误触发换台、暂停或菜单操作。
- 屏幕亮度和自动熄屏选择会保存在设备中，重新开机后继续生效。
- 新增网络设置，可连接新网络、查看所有已保存网络、设为首选或逐个删除。
- 从设置进入新网络扫描后可长按确定返回，并重新连接原有网络。
- 设置新增“蓝牙”彩蛋入口，播放用户提供视频的前 8 秒。
- 彩蛋使用 120×160 JPEG 解码并以 2 倍像素直接输出到 240×320 全屏，帧率为 20 fps，音频为 16 kHz 单声道；播放结束自动恢复电台，播放中按任意键可提前退出。
- 全屏直写路径按 TJPGD 的 BGR 字节顺序转换为面板 RGB565，保留原视频色彩。
- 彩蛋是趣味视频，不提供真正的蓝牙耳机或蓝牙音箱连接功能。
- 彩蛋资源独立于主程序；未安装资源包时会提示“彩蛋未安装”，不影响收音机的其他功能。
- 主界面顶部品牌改为 `LEO RADIO`。
- 分享版已清理个人数据：配网热点使用通用名称，固件与源码均不包含任何 Wi‑Fi 凭据、MAC 或本机路径。
- 长按确定键进入全中文设置。
- 设置第一项为音量，上、下键可实时调节，确定键返回。
- 设置第二项为城市电台，可选择自动定位、北京、上海、广州、深圳、长沙、杭州、成都。
- 手动选择城市后，后台加载该城市按热度排序的可播放电台。
- 每次完成配网后仍优先进行网络定位，并自动加载用户当前城市的电台。
- 配网热点固定为通用名称 `LEO Radio`，不再包含任何设备或个人标识。
- 保留设备屏幕搜索 Wi-Fi、输入密码和网页配网两种方式。
- 设置菜单继续使用低对象数量设计，避免重现旧键盘的界面内存耗尽问题。

## 按键操作

- 主界面：上、下键换台；短按确定键播放或暂停；长按确定键进入设置。
- 设置菜单：上、下键选择；确定键进入。
- 音量：上、下键调节；确定键返回设置。
- 城市电台：选择自动定位或七个城市，确定后立即返回主界面并加载电台。
- 定时播放：选择无定时或播放时长，确定后开始计时并返回设置。
- 屏幕设置：选择亮度或自动熄屏，短按确定循环切换，长按确定返回。
- 网络设置：可连接新网络，或进入已存网络列表进行首选和删除操作。
- 蓝牙：播放 8 秒视频彩蛋；播放中按任意键退出并恢复电台。
- 设置各级页面长按确定键：返回上一级；设置首页长按确定键返回主界面。

## 配网

- 首次安装后设备会进入配网，热点名称固定为通用名称 `LEO Radio`。
- 可以直接在设备上选择附近的 2.4 GHz Wi-Fi 并输入密码。
- 也可以让手机连接该热点，访问 `http://192.168.4.1` 完成配网。
- 已保存网络存在时，设备先自动连接；30 秒内没有可用网络才进入配网。
- 配网成功后设备根据网络位置搜索当地城市电台。

## 分享给他人

- 固件、彩蛋资源与源码均不包含制作者的 Wi‑Fi 名称、密码、MAC 地址或本机路径。
- 新设备只需写入应用 `0x10000` 和彩蛋资源 `0x360000`，切勿复制任何已配网设备的 NVS。
- 若转交的是已经配过网的实体设备，请先执行
  `esptool.py erase_region 0x9000 0x6000` 清除本机 Wi‑Fi 记录，再写入分享版应用。
- 清除后首次开机会自动打开配网热点 `LEO Radio`，由新主人自行配网。

## 安全升级

- 应用升级包从地址 `0x10000` 写入，只更新应用程序。
- 彩蛋资源包从地址 `0x360000` 写入；该地址是实机分区表中 `cardid` 与 Recovery 之间已检查的空闲区域。
- 不擦除整片 Flash，不覆盖设备的分区表、`cardid` 数据或 Recovery。
- 应用升级会保留已有 Wi-Fi、屏幕设置及其他设备数据。
